# 空中之島

這是一個不用安裝、不需伺服器的靜態網頁方塊遊戲。直接用瀏覽器開啟 `index.html` 即可遊玩。遊戲程式庫和素材都放在本資料夾中；不需連網下載遊戲檔案。

## 操作方式

- 點「進入島嶼」後，使用 `W A S D` 移動、空白鍵跳躍，移動滑鼠轉動視角。
- 按住滑鼠左鍵挖方塊；靠近掉落物即可自動撿起。
- 用數字鍵 `1–6` 選物品，對準方塊按滑鼠右鍵放置；選擇花朵並對準草地可種花。
- 掉出島嶼會自動回到起始位置。按 `R` 開始或停止下雨；全螢幕按鈕可切換全螢幕。
- 按 `Esc` 釋放滑鼠，點一下遊戲畫面即可回到遊戲。
- 下雨時，種下的花每淋雨約 10 秒會長高；遊戲會隨時間切換日夜。
- 島上有葉磚藏著通往地下洞穴的入口，附近還有兩座可跳去的小浮島。收集 10 個掉落方塊或種下 3 朵花可取得畫面上的徽章。

## 專案檔案

- `index.html`：遊戲頁面
- `styles.css`：畫面樣式與操作介面
- `game.js`：遊戲邏輯
- `vendor/three.min.js`：內附的 three.js 程式庫
- `sky-island-assets/sky-island-assets/`：課程提供的方塊材質、圖示和挖掘裂痕

## 驗收狀態

新增的探索與任務功能已寫入遊戲，但尚未在目標電腦上逐項實際遊玩驗收；測試清單見 `VERIFY.md`。每秒 30 格是作業目標，需在學校電腦全螢幕實測確認。
